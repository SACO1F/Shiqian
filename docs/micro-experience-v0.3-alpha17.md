# 拾签 v0.3.0-alpha.17：操作反馈与微交互

更新日期：2026-10-09。

## 本次变化

本次按 [React Bits 动效评估](react-bits-motion-plan-2026-10-09.md) 的五项体验范围实施。动效由本项目 CSS 与浏览器 Web Animations 实现，没有引入 React Bits 组件源码或增加 Motion、GSAP、OGL 运行依赖。

### 标签弹窗与菜单

弹窗以约 200ms 的短位移和淡入展开，关闭按钮、Escape 或点击背景触发约 140ms 收回。保存完成或菜单选择后直接转入下一状态，避免操作完成后继续等待动画。收回期间停止弹窗内交互，重复关闭不会触发多次回调。焦点限制在弹窗内，关闭后返回原操作按钮。

浮窗九点菜单增加入场和收回过渡，使用连续滑动的选项高亮。方向键、Home、End 可以移动焦点，跳过不可用选项；Escape 关闭并返回九点按钮。快速重新打开时清除旧关闭计时器。

### 多选勾选

瀑布流和列表的勾选框保持挂载，以轻微缩放、淡入和勾线绘制反馈选中状态；取消时平滑隐藏。文件卡片、点击区域和布局尺寸不随勾选动画改变。Ctrl 多选仍按现有规则工作。

### 标签出现与 AI 接受

新标签进入侧栏或实际固定到浮窗时轻微滑入。文件新增标签及接受 AI 标签时，详情标签和图片内标签有局部反馈。

接受 AI 标签仍立即更新标注状态、去掉待确认标记并进入可添加标签池及浮窗；动效不延迟数据提交。普通刷新、切换文件、虚拟滚动重挂载不重复播放标签入场。其他文件尚未确认的同标签关联继续保留 AI 标记。

### 最近三步记录

新记录短距离滑入，原有记录平滑移动，超出三步的旧记录淡出。逻辑记录和可访问列表始终只保留三条；离场副本不接收输入且不进入可访问内容，动画结束后立即清理。重启／刷新恢复原记录时不重播入场。继续不提供浮窗撤销按钮。

### AI 状态

详情区区分等待、处理中、标签待确认、完成、失败、未支持和已取消。处理中显示小型点阵，任务结束后停止循环。批量选择显示实际任务状态数量与待确认标签数量，不使用模拟百分比。

识别中按钮禁用，减少重复排队。失败／取消后提供“重试识别”；活动任务显示“取消识别”，仅取消当前所选文件。设置中的“取消队列”继续取消全部活动任务。

已发往模型服务的请求无法通过此按钮撤回；取消会在请求结束时丢弃结果。取消其他文件不会使未选任务失效；重试生成新任务版本，旧响应不能覆盖新任务。内容提取后、发送前增加任务状态检查。

## 动态效果与主题

浅色、深色模式继续使用绿色主题与既有玻璃按钮。系统选择减少动态效果时，弹窗、菜单、勾选及局部标签／记录直接切换，点阵保持静态，不循环闪动。

## 验证与交付

验证使用独立 QA 资料库、合成文件与本机模拟模型服务，未操作个人资料库。最终测试记录见 `docs/evidence/micro-experience-*.log`；实际模型质量、完整多屏混合 DPI 手势和全新 Windows 安装不属于本轮验证范围。

- 既有 AI 自动标注回归 10 组、标签与多选回归 6 组、瀑布流回归 35 个场景通过。
