# v0.3.0-beta.2 验收记录

日期：2026-10-10。环境：Windows x64，本机 WebView2。测试使用 `qa/` 隔离资料库和合成文件，没有修改正式用户资料库。

## 核心回归

`cargo test --manifest-path src-tauri/Cargo.toml --lib --offline`：**88 项通过、2 项忽略、0 失败**。忽略项沿用原生可见 Shell 探针和由父测试单独执行的异常退出子进程；父级异常退出恢复测试通过。

新增 5 项验证：

1. 在复制阶段用同步屏障暂停任务，确认共享 Store 可立即获取，查询和备注写入可执行；取消后备注保留，原记录数量不变，任务创建的副本和恢复标记清理。
2. 资料包历史限定 12 项，完成、失败、取消状态区分。
3. 诊断固定字段排除私有文本，已有报告文件不被覆盖。
4. 恢复提示跨启动保留；备份日期记录为本机元数据，恢复后记录保护备份。
5. AI 重试只改变失败任务，完成、取消、未支持与其他活动状态保留。

证据：[beta2-core.log](evidence/beta2-core.log)。

## 桌面实际操作

最终发布构建使用真实 Tauri IPC / WebView2，1 GB 合成原文件与资料包：

- 文件加入部分失败后，补齐文件，使用任务面板只重试失败路径。
- 从资料包对话框点击「后台运行」回到工作台，在校验准备期间执行 6 次查询，最终构建耗时 **5、6、5、5、5、6 ms**；这是本机小资料库 IPC 实测，不能外推为大图库性能。
- 后台编辑既有备注成功；并发备份恢复及退出被拒绝；取消资料包后新增副本清理、记录不增加、备注和原文件保留。
- 小资料包成功追加导入，同包再次导入被拒绝。
- 最近备份日期、恢复前保护备份、诊断预览和导出 API 通过。
- 浅色、深色、960px 和减少动态效果检查通过，无页面脚本异常；截图在模态动画完成、计算透明度为 1 后检查。
- 重启发布程序后，文件身份、备注、保护备份状态保存，已关闭恢复提示不再出现，任务会话历史重置。

原生诊断保存文件选择器未自动操作；验证了预览界面、导出按钮可用及真实导出 IPC。第一次测试误把原生选择器当成可在网页中替代的调用，已修正测试方式。第一次完整构建的工具下载停滞后，使用官方发布的 NSIS 和插件副本，按构建器固定 SHA-1 校验通过，再完成 NSIS 打包。

证据：[最终构建桌面流程](evidence/beta2-final-desktop.log)、[最终构建重启](evidence/beta2-final-restart.log)、[前一轮发布版桌面流程](evidence/beta2-release-desktop.log)、[前一轮发布版重启](evidence/beta2-release-restart.log)、[截图检查](evidence/beta2-capture.log)。初始调试尝试保留为历史日志，不作为最终通过证据。

## 持续操作

隔离发布程序持续操作 **600.038 秒、3308 次备注保存／查询循环**，同时切换瀑布流与列表、主题、打开／关闭浮窗并刷新页面。文件数量稳定，没有页面脚本异常。

主页面垃圾回收后 JS 堆由 **3,359,668 → 4,308,068 字节**，DOM 节点 **505 → 571**。这是不同界面末态下的观察数据，尚不足以判断全天内存走势，也不是总 WebView / Rust 内存测量。该项不能替代全天使用、系统休眠恢复或真实大图库验收。

证据：[持续操作记录](evidence/beta2-soak.log)。最终构建在该项之后补充了进度初始状态清理与诊断预览键盘聚焦；最终发布程序已重新通过上述 1 GB 桌面流程和重启验证。
