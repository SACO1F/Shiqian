# 拾签 · 桌面端 v0.2.0

用标签、备注和组合查找，重新找到分散在本机的文件。首版面向 Windows 11 x64，以本地资料库为中心，无需账号。

当前实现状态与后续迭代见 [开发路线](roadmap.md)。工作区在 2026-10-02 清理了依赖、构建缓存及测试临时文件，继续开发前先执行 `npm ci`；源码、测试脚本和验证证据完整保留，详见 [清理记录](cleanup-2026-10-02.md)。

## 已实现

- 独立置顶标签浮窗；内置「灵感／参考素材／待处理／已完成」，支持创建、固定或移除最多 24 个预设。
- 拖标签到 Windows 桌面、资源管理器的具体文件或拾签文件卡片进行标注；也支持将多个文件拖到浮窗标签上。
- 外部文件自动加入资料库并标注；重复操作不产生重复关联；支持撤销；主窗口关闭后浮窗可继续使用。
- 加入文件、文件夹及其子目录；原生拖放；显示加入统计、失败详情并支持取消。
- 一份文件关联多个标签；创建、搜索、重命名、删除标签；批量添加与移除，显示部分拥有的状态。
- 文件备注自动保存，失败时保留草稿；备注与文件属性分别校验版本，避免覆盖后续修改。
- 搜索文件名、标签和备注；多个词交集匹配；标签全部／任一／排除；按类型、可用性、修改日期、目录筛选。
- 网格与列表视图、虚拟滚动、分页加载；侧边详情、收藏、待整理、最近加入及异常文件范围。
- JPEG、PNG、WebP 预览；PDF 首页预览；纯文本预览。Office 等格式通过系统默认程序打开。
- 默认程序打开、在文件夹显示、复制路径；文件缺失或被替换时保留标注，支持手动重新关联。
- 软移除记录；会话内最近 20 步撤销，涵盖文件标签、收藏、移除、标签重命名／删除、重新关联。
- `.sqtagbackup` 标注备份、完整性校验、恢复前自动保护备份和中断检测。
- 跟随系统／浅色／深色主题、卡片密度、视图偏好、预览缓存清理。

## 使用

推荐运行发布目录中的 Windows x64 安装程序。安装包按当前用户安装。系统需要 Microsoft Edge WebView2 Runtime；安装器会检查该组件，缺少时获取并安装。已经具备运行环境后，核心功能无需网络。

也可直接运行单文件 `shiqian.exe`。它同样使用系统 WebView2 和用户应用数据目录，并非把资料库存入 EXE 旁边的便携模式。

1. 点击“加入文件”，选择文件或文件夹，也可以把它们拖入窗口。
2. 选中一份文件，在右侧输入标签名，按 Enter 创建或选择已有标签。
3. 在备注中记录用途或下一步，停止输入约 500 ms 后自动保存。
4. 点击侧栏标签快速筛选，或使用“筛选”组合多个条件。搜索框同时匹配名称、标签与备注。
5. 在“偏好设置”导出标注备份；需要回滚或迁移时选择“从备份恢复”。

本版的标注指标签和纯文本备注。原文件仍在原位置，拾签不修改文件内容。备份包含文件位置、标签、备注、收藏和设置，**不包含原文件**。

## 标签浮窗

在工作台左下角点击「标签浮窗」。浮窗始终置顶，可以拖动标题区域调整位置，点击上箭头收起成小条。

按住标签拖到具体文件后松手，自动添加该标签；再拖另一枚标签即可叠加标注。拖拽过程中按 Escape 取消。文件尚未入库时自动加入。资源管理器空白处、文件夹和系统虚拟项不作为标注目标。

也可以在资源管理器选择多个文件，将它们拖到浮窗中的某一枚标签上，一次标注整批文件。单次最多 1,000 个文件。遇到无效文件会取消这一批写入，显示原因。键盘用户可先选中标签，再使用「选择文件标注」。

点击右上角预设管理按钮，新建自己的标签或勾选已有标签。取消勾选只影响浮窗预设，文件已有标签会保留。预设与标注都存入同一本地数据库，包含在标注备份中。

浮窗开启时关闭工作台会隐藏工作台；点击浮窗右上角「打开工作台」可返回。关闭浮窗时若工作台隐藏，会先恢复工作台。关闭工作台且浮窗未显示时退出程序。

Windows 文件识别使用 Shell 文件项和 UI Automation；仅接受唯一对应的本地文件路径。第三方文件管理器、浏览器内图片和虚拟文件列表暂不支持向外拖标签，可通过拖入真实文件或文件选择器标注。文件夹不会递归应用标签。

## 数据与恢复

正式运行时，资料库保存在 `%APPDATA%\local.shiqian.desktop`，WebView 自身状态由 Tauri 保存到用户本地应用数据目录。以“偏好设置”显示的数据目录为准。

`library.sqlite` 使用 WAL 和外键约束。缩略图存放于 `cache`，可重新生成。恢复前的保护备份存放在 `backups`，名称以 `before-restore-` 开头。恢复操作会清空会话撤销历史。

没有自动追踪文件移动：启动、手动刷新和访问前会检查原文件。移动或更换磁盘后，可以在“需要关注”中重新关联。相同位置出现不同文件身份时需要确认关联，不会自动继承旧文件的标注。

未保存备注保存在该资料库对应的 WebView 本地草稿中。发生保存冲突时，可重试或重新读取；重新读取会明确询问是否放弃当前草稿。

## 构建

开发环境：Windows x64、Node.js、Rust MSVC 工具链、Visual Studio C++ Build Tools、WebView2。本次构建使用 Node.js 25.8.1、Rust 1.97.1；依赖通过 `package-lock.json` 和 `Cargo.lock` 锁定。

```powershell
npm ci
npm run desktop
```

前端热更新开发由 Tauri 自动启动。仅运行 `npm run dev` 会启动前端服务器，但文件操作需要桌面原生后端，不能把普通浏览器页面当作成品使用。

```powershell
npm run build
npm run test:core
npm run package
```

安装包输出到 `src-tauri/target/release/bundle/nsis`。PDF Worker、字体、CMap 与 WASM 资源在构建前从本地依赖复制，发布时随应用打包，不依赖 CDN。

源码使用 React + TypeScript + Vite，桌面宿主为 Tauri 2，文件操作与数据库逻辑位于 Rust 后端，SQLite 随后端构建。

## 验证与范围

测试只使用 `qa` 下的合成文件及临时资料库。设置 `SHIQIAN_DATA_DIR` 可隔离 SQLite 与 WebView 数据；未设置时使用正常应用数据位置。

桌面验证需要 Playwright。将 `PLAYWRIGHT_MODULE` 指向其可加载模块，或调整脚本中的默认路径。先运行 `scripts/make-fixtures.py` 生成合成图片、文本和 PDF，再使用 `scripts/launch-qa.cjs` 启动测试实例，最后执行 `node scripts/desktop-smoke.cjs`。合成素材脚本需要 Pillow 与 ReportLab，它们不是最终用户运行软件的依赖。

自动化测试会清空测试库中的标签和备注，脚本会先检查资料库路径在当前工程的 `qa` 子目录内。不要将测试脚本用于个人资料库。

本版为可体验、可继续迭代的桌面首版。图片预览限制为 100 MB／40 MP，PDF 为 30 MB 且只预览首页，文本最多预览前 200 KiB。超出限制或损坏文件会提示使用外部程序。全文内容索引、OCR、图片区域标记、云同步和浏览器扩展属于后续版本。

本次浮窗功能说明见 `docs/floating-tags-v0.2.md`，测试证据与未覆盖场景见 `docs/validation-v0.2.md`；首版记录保留在 `docs/validation.md`。第三方组件声明见 `THIRD_PARTY_NOTICES.md`。
