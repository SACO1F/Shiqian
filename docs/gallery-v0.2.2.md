# 拾签 v0.2.2：瀑布流布局修复

更新日期：2026-10-04。

## 列数操作

工具栏按「－ → 滑杆 → ＋ → 当前列数」排列：

- **＋ 增加一列**，例如从 3 列变成 4 列。
- **－ 减少一列**，例如从 4 列变成 3 列。
- 滑杆直接设置列数；默认 3 列，支持 2～8 列。达到当前可用上下限时，对应按钮禁用。
- 可用上限随窗口、左侧菜单和详情面板占用的空间调整。恢复窗口宽度后，恢复已保存的列数偏好。

列数越多，每张图片越小；列数越少，每张图片越大。列数及侧栏状态保存在本地资料库，重启后继续使用。

## 修复图片重叠

v0.2.1 中，在切换列数、窗口宽度变化或重载时，可能丢失已经测得的卡片高度，使后续图片按默认高度定位并覆盖前面的图片。v0.2.2 在布局尺寸变化后，先使旧高度失效，再在绘制前读取当前卡片的真实高度，重新计算位置。

本次修复保留图片原比例、虚拟渲染、分页和悬停名称。图片常规元信息仍默认隐藏；完整信息在详情面板查看。极端长图继续受卡片高度上限约束，完整内容可按空格预览或使用默认程序打开。

## 使用修复版

先正常退出正在运行的旧版，再启动 v0.2.2 安装包或独立 EXE。沿用原来的本地资料库，无需重新导入或重新标注。本次没有数据库结构变更。

完整浏览和侧栏功能见 [v0.2.1 指南](gallery-v0.2.1.md)，其中旧版「加减号控制图片缩放」的说明由本页的列数操作替代。

测试步骤、旧版复现与新版证据见 [v0.2.2 验证记录](validation-v0.2.2.md)。
