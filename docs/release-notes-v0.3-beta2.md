# v0.3.0-beta.2

日期：2026-10-10。

- 大资料包的校验、复制与文件检查移到资料库锁之外，最后事务保存标注；搜索和备注编辑可在后台准备期间继续使用。
- 资料包对话框新增「后台运行」，工作台底栏新增任务面板；按阶段显示字节与文件进度，保留本次运行最近 12 项资料包结果。
- 文件加入失败可重试已记录的失败路径；AI 支持只重试失败任务。
- 资料包和备份恢复互斥，后台任务未完成时阻止退出，避免正常关闭直接中断复制。
- 偏好设置显示最近标注备份或恢复前保护备份日期；中断恢复提示跨启动保留，并提供查看和关闭入口。
- 新增诊断预览与 Markdown 导出，采用固定字段排除文件名、路径、内容、备注、标签名称、AI 服务配置和密钥。
- 数据库格式仍为 schema 2，保留 Beta.1 数据和既有 AI 标签确认规则。

本地交付与验收范围见 [使用说明](beta-v0.3-beta2.md) 和 [验收记录](validation-v0.3-beta2.md)。干净电脑安装、缺少 WebView2、多屏混合 DPI 和全天运行仍需实机验收。
