# 拾签使用说明书

**适用版本：v0.3.0-beta.9 · Windows x64**  
**更新日期：2026-10-10**

拾签通过标签、备注与搜索整理本地图片和文件。一份文件可以拥有多个标签，原文件通常保留在原来的文件夹中。当前的“标注”指添加标签与文字备注，不是直接在图片上绘制或圈选区域。

本版为小范围试用的 Beta 候选版本。初次使用建议先加入几份文件，熟悉后再整理更多资料。

## 1. 获取、安装与首次启动

下载页面：[拾签 v0.3.0-beta.9](https://github.com/SACO1F/Shiqian/releases/tag/v0.3.0-beta.9)。

| 文件 | 用途 |
|---|---|
| `Shiqian-v0.3.0-beta.9-Windows-x64-setup.exe` | 推荐使用的安装包 |
| `Shiqian-v0.3.0-beta.9-Windows-x64.exe` | 已有 WebView2 环境时可直接运行的独立程序 |
| `Shiqian-v0.3.0-beta.9-source.zip` | 开发源码，普通使用者不需要 |
| `SHA256SUMS.txt` | 发布文件校验清单 |

运行安装包，按安装向导完成安装，再启动拾签。安装按当前 Windows 用户进行。系统需要 Microsoft Edge WebView2 Runtime，安装器会检查并处理该运行环境；缺少组件时可能需要联网。

独立 EXE 同样使用 Windows 用户应用数据目录，**不是把资料库存到 EXE 旁边的便携模式**。把 EXE 发给另一台电脑，不会同时带走标签和资料库。

### 从 alpha.10 升级

可以直接升级到 Beta.9，不需要依次安装中间版本。按以下顺序操作：

1. 在 alpha.10 的“偏好设置 → 备份与恢复”中，点击“导出标注备份”，保存 `.sqtagbackup`。
2. 重要原文件另行备份。标注备份不包含原文件。
3. 如需额外保险，先在偏好设置打开数据目录，完全退出软件后，把整个数据目录复制到另一位置保存。
4. 先关闭标签浮窗，再关闭工作台，确保旧版退出。等待正在处理的任务结束。
5. 运行 Beta.9 安装包，使用原来的 Windows 用户和通常的安装位置；不必先手工卸载旧版。若安装器提示处理旧版本，保留应用数据，不要勾选删除应用数据。
6. 打开新版，在偏好设置确认版本为 `0.3.0-beta.9`，核对文件数量、标签、备注、收藏及浮窗。
7. 使用新版快捷方式。不要同时运行旧版和新版操作同一资料库。

alpha.10 与 Beta.9 的应用标识均为 `local.shiqian.desktop`，均按当前用户安装，数据库均为 schema 2。本次已用 alpha.10 创建合成资料库，再由 Beta.9 打开，验证记录、标签、备注、收藏、主题、侧栏宽度和浮窗标签保留；alpha.10 备份检查及恢复通过。

**验证边界：**该测试验证实际程序的数据兼容性，未在另一台实体电脑上执行安装器覆盖安装或卸载测试。同事电脑的安装路径、运行环境和历史数据仍须在升级后核对。

如果旧版是独立 EXE，可以安装新版后打开，通常会读取同一 Windows 用户的既有资料库。若打开后看不到旧数据，先检查偏好设置中的数据目录和 Windows 用户，不要立即重新导入或恢复，以免把“目录不同”误认为“数据丢失”。

## 2. 五分钟开始使用

1. 点击工作台右上角“加入文件”，加入几份图片或文档。
2. 点击一份文件，在右侧详情中添加“参考素材”“待处理”等标签。
3. 为文件写一段备注，记录用途或下一步，等待显示“已保存”。
4. 点击左侧对应标签，找回刚才标注的文件。
5. 点击左下角“标签浮窗”，尝试把标签拖到工作台中的具体文件上。
6. 在偏好设置导出一份标注备份。

## 3. 工作台界面

### 顶部与侧栏

窗口最上方左侧依次为：撤销、刷新文件状态、侧栏收起／展开。右侧是最小化、最大化／还原、关闭。标题栏空白区域用于移动窗口，双击可切换最大化；普通窗口边缘可调整大小。

左侧菜单可拖动右边缘调整宽度，缩小到阈值后自动收起。点击标题栏中的侧栏按钮可再次展开。

| 入口 | 作用 |
|---|---|
| 全部文件 | 浏览资料库中的文件记录 |
| 待整理 | 查看尚未关联任何标签的文件 |
| 我的收藏 | 查看已收藏的文件 |
| 最近加入 | 查看最近加入的资料 |
| 需要关注 | 查看原文件缺失、状态异常等需要处理的记录 |
| 标签索引 | 按标签筛选；文件夹标签与普通标签分组显示 |
| 标签浮窗 | 打开独立标签浮窗 |
| 偏好设置 | 主题、密度、自动标注、资料交接、备份和本地存储 |

### 瀑布流与列表

通过右上方布局图标切换瀑布流与列表。瀑布流可用列数滑块与加减按钮调节列数；“+”增加列数，“−”减少列数。

瀑布流图片上的文件名和标签在悬浮时显示，标签颜色与对应标签保持一致。列表显示文件名、标签、修改时间和大小等行内信息。

“切换详情面板”按钮控制右侧详情区域是否显示。排序选择器、升序／降序和文件操作始终同时保留；窗口较窄时工具栏可换行。

## 4. 加入文件与文件夹

使用“加入文件”下拉入口选择文件或文件夹，也可以把本地文件／文件夹拖入工作台。文件夹导入会处理其子目录内的文件。

普通加入只建立资料库记录与标注，不把原文件统一搬到应用目录。不要因为已经加入拾签，就删除原文件所在的文件夹。

导入较多文件时，可查看加入进度与结果。取消普通加入任务后，已经成功加入的记录保留，未完成的部分停止继续处理。

## 5. 选择、多选与文件操作

- 普通点击选择一份文件；再点击同一个单独选中的文件可取消。
- 点击另一份文件切换选择。
- 按住 Ctrl 点击可增加或移除选择。
- 按住 Shift 点击可选择已加载结果中的连续区间。
- “全选结果”选择当前查询结果，单次批量处理最多 1,000 个文件；超过上限请缩小筛选范围。
- “取消选择”清空选择。两个按钮用胶囊高亮反馈选择状态。

选中文件后，工具栏三个图标依次为收藏、导出资料包、移除。悬浮或键盘聚焦时显示功能名称；未选中文件时这些操作禁用。

**移除**删除的是拾签中的文件记录，不删除磁盘上的原文件。确认对话框会说明影响，可取消；支持的记录操作可以通过撤销恢复。

## 6. 添加、修改和删除标签

### 为文件添加标签

选中文件，在详情中的“添加标签”输入框搜索或输入标签名。点击已有标签，或按 Enter 创建／使用标签。

也可以使用工作台右下角的“添加标签”悬浮按钮。未选中文件时可创建普通标签；选中文件时可为所选文件添加标签。

文件夹标签不出现在手动添加候选中。已应用于全部所选文件的标签不重复展示；只有部分文件拥有的标签仍可选择，用于补齐其他文件。

### 为多份文件共同添加标签

先通过 Ctrl、Shift 或“全选结果”选中多份文件，再添加标签。已经拥有该标签的文件不会产生重复关联，其他文件会补齐。

如果想给同一标签下的文件一起添加新标签：先点击左侧原标签筛选，再全选结果，最后添加新标签。

### 修改和删除

在左侧标签索引的编辑入口、标签管理界面，或浮窗标签右侧的九点按钮中修改标签名称。重命名会同步到关联文件及浮窗中的同一标签。

区分两种操作：

| 操作 | 影响 |
|---|---|
| 从某个文件移除标签 | 只解除该文件与标签的关联 |
| 删除整个标签 | 从标签库删除，并解除相关文件关联 |
| 从浮窗移除快捷标签 | 只调整浮窗预设，文件已有标签保留 |

## 7. 标签浮窗

点击左侧底部“标签浮窗”。浮窗提供常用标签、添加标签、选择文件标注和最近操作记录。

### 三种标注方式

1. **拖标签到文件：**按住浮窗中的标签，拖到工作台具体文件卡片，或 Windows 桌面／资源管理器中的具体本地文件，松手完成标注。
2. **拖文件到标签：**在资源管理器选择文件，把它们拖到浮窗某个标签上，可批量添加同一个标签。
3. **选择文件标注：**先点击浮窗中的标签，再点击“选择文件标注”，从文件选择器中选择文件。

拖到工作台卡片时会有命中高亮和鼠标提示。拖动过程中按 Escape 可取消。向未入库文件添加标签时，会把它加入资料库；**通过标注入口加入的文件不会自动进行 AI 识别**。

外部拖拽只处理明确对应的本地文件；资源管理器空白处、文件夹、虚拟项、浏览器内图片和第三方文件管理器不保证支持。遇到问题可改用文件选择器或先加入工作台。

### 标签与窗口管理

- 右下角“添加标签”可新建或加入已有普通标签；文件夹标签不作为浮窗预设。
- 在工作台创建或使用普通标签后会自动同步到浮窗；标签较多时可滚动浮窗，并按使用习惯调整快捷预设。
- 标签右侧九点按钮可编辑、导出对应文件、删除或调整浮窗预设。
- 标题栏图钉按钮切换置顶；上箭头收起浮窗；打开工作台按钮返回主窗口。
- 窗口边缘可调整大小，移动位置与展开尺寸会保存。
- 浮窗底部仅记录最近三步操作，不提供浮窗撤销入口；支持撤销的工作台操作使用工作台撤销。

## 8. 搜索、筛选与排序

点击“全部文件”等页面标题右侧的放大镜展开搜索栏，或按 Ctrl + F。搜索可匹配文件名、标签与备注。

点击“筛选”展开更多条件，可按文件类型、状态、目录、日期和标签组合筛选。“满足全部标签”要求同时拥有所有指定标签；“满足任一标签”匹配其中至少一个；排除标签用于去掉不需要的结果。

左侧标签索引采用单选筛选。更复杂的多个标签组合请在筛选面板设置。没有结果时，先清除条件，再检查关键词和原文件状态。

排序支持加入时间、修改时间、名称和文件大小，并可切换升序／降序。排序与文件操作同时显示，不需要取消选择才能看到排序入口。

## 9. 文件详情、预览与备注

选中文件后，可在详情中查看标签、备注与文件信息，并执行打开文件、在文件夹中显示、复制路径等操作。

单选时按 Space 打开放大预览，再按 Space 或 Escape 收起。按 Enter 用系统默认程序打开文件。图片、PDF 首页和纯文本可在拾签预览；其他格式或超出预览限制时使用系统默认程序打开。

备注自动保存，停止输入后等待“已保存”。不要在保存失败时直接清理本机应用数据。发生冲突时，可重试，或明确选择重新读取数据库中已保存的内容。

## 10. 文件夹自动标签与 AI 标注

### 文件夹标签

偏好设置中开启“导入时使用所在文件夹名称作为标签”，新加入文件会得到直接父文件夹名的标签。例如 `素材/海报/封面.png` 对应“海报”。

递归导入时按每个文件的直接父文件夹处理，不把所有上级文件夹名都加上。可以使用“为已有文件补齐标签”处理既有记录。关闭开关后，已添加的文件夹标签保留。

### AI 自动标注

在偏好设置填写服务地址、模型名称及需要的 API Key，保存配置并开启 AI 自动标注。图片分析需要支持视觉输入的模型。

AI 会优先复用已有标签；允许创建新标签时，找不到合适标签可生成建议。未经确认的建议带有 AI 标识，尚不进入手动添加标签库和浮窗；接受后去掉 AI 标识，进入普通使用流程，并同步到浮窗。拒绝或移除建议后，孤立的 AI 标签会清理；仍被其他文件使用的标签不会误删。

文件详情中的“AI 重新识别”可更新待确认建议，保留手工、文件夹和已确认标签。

**数据发送范围：**启用后，新导入图片的预览或文档最多 12,000 字符的摘录，会连同文件名与已有标签池发送到配置的服务。本机模型使用本机服务地址；远程服务可能收费。API Key 按当前 Windows 用户加密，不包含在标注备份中。

## 11. 导出同标签文件与资料交接

### 只导出同标签原文件

在标签管理或浮窗九点菜单中选择导出该标签文件，指定目标文件夹。软件复制对应原文件，原位置的文件保留。

这适合把同类文件整理成一个可分享文件夹。若还需要带走标签、备注和收藏，请使用资料包。

### 导出资料包给同事

1. 选中需要分享的文件，点击工具栏“导出资料包”；也可从“偏好设置 → 资料交接”打开导出。
2. 确认导出范围并保存 `.sqtagpack`。
3. 等待完成，把资料包、安装包和本说明书发给同事。
4. 同事在“偏好设置 → 资料交接 → 导入资料包”选择文件，先校验，再选择接收目录并导入。

资料包携带原文件与对应标注，接收时把文件复制到接收目录，并加入同事自己的资料库。资料包可能含敏感文件与备注，发送前请确认范围。

## 12. 备份与恢复

“偏好设置 → 备份与恢复 → 导出标注备份”保存 `.sqtagbackup`。建议在升级、批量调整标签或迁移电脑前导出。

| 类型 | 包含内容 | 适合用途 |
|---|---|---|
| `.sqtagbackup` 标注备份 | 文件位置、标签、备注、收藏、相关设置；不含原文件和 AI 密钥 | 同一资料库备份、恢复 |
| `.sqtagpack` 资料包 | 选定原文件及其标注 | 发给同事、换电脑交接资料 |
| 同标签文件夹导出 | 匹配标签的原文件副本 | 普通文件夹分享 |

“从备份恢复”会替换当前资料库标注状态，恢复前会自动生成保护备份。不要把它当作“追加导入别人资料”的入口；追加资料请使用资料包。

换电脑时原文件路径可能变化，仅恢复标注备份不会自动搬运或修复原文件。优先使用资料包交接，或另行复制原文件后重新关联。

## 13. 后台任务与退出

资料包校验、导入、导出可后台运行，点击底部“任务”查看进度、失败原因、重试或取消。取消资料包任务需等待收尾完成；普通文件加入取消后已加入记录保留。

浮窗仍显示时，关闭工作台会隐藏主窗口；从浮窗可重新打开。**完全退出：先关闭标签浮窗，再关闭工作台。**升级前应完全退出，避免替换仍在运行的程序。

任务未结束时，关闭会进行检查并提示等待或取消，不建议强制结束进程。

## 14. 数据位置与常见问题

正式资料库通常位于 `%APPDATA%\local.shiqian.desktop`，以“偏好设置 → 本地存储”显示的数据目录为准。缓存可以清理，预览会重新生成；不要随意删除 `library.sqlite` 或整个数据目录。

| 问题 | 处理方法 |
|---|---|
| 升级后仍显示 alpha.10 | 退出旧版，检查启动的是新快捷方式／新 EXE；在偏好设置确认版本 |
| 升级后看不到原资料 | 检查是否为同一 Windows 用户和同一数据目录，先备份，不要立即覆盖恢复 |
| 文件显示缺失或异常 | 点击刷新，检查原文件是否移动、删除或磁盘断开；在详情重新关联正确文件 |
| 找不到文件 | 清空搜索和筛选；检查左侧是否只选中了某个标签 |
| 浮窗关闭后工作台重新出现 | 工作台之前被隐藏，软件会先恢复主窗口，属于预期行为 |
| 标签拖拽无效 | 改用“选择文件标注”或先加入工作台；检查目标是否为明确的本地文件 |
| AI 不识别 | 检查开关、保存后的服务配置和模型能力；标注入口加入文件本来就跳过 AI |
| 确认标签后浮窗未显示 | 检查浮窗快捷预设与当前内容；先重新打开浮窗，必要时导出诊断反馈 |
| 预览打不开 | 尝试“打开文件”使用系统默认程序；检查文件状态与格式 |

反馈问题时记录版本、操作步骤和截图。偏好设置可预览并导出诊断报告；诊断仅含版本、计数及任务状态，不含文件名、路径、正文、备注、标签名或 AI 服务配置，不会自动上传。

## 15. 常用快捷键

| 快捷键 | 操作 |
|---|---|
| Ctrl + F | 展开并聚焦搜索 |
| Ctrl + 单击 | 增加或移除文件选择 |
| Shift + 单击 | 连续选择已加载区间 |
| Ctrl + A | 文件区域聚焦时选择已加载结果，最多 1,000 项；完整当前查询请用“全选结果” |
