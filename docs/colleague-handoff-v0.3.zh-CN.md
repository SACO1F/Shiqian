# 拾签 v0.3：发给同事与跨电脑资料包交接

更新：2026-10-11。适用于 v0.3.0-rc.4。软件安装与资料交接是两个动作。新包为 v2 格式，发送和接收双方都应使用 RC.2 或后续支持 v2 的版本；新版可以读取旧包。

## 先安装软件

发送 `Shiqian-v0.3.0-rc.4-Windows-x64-setup.exe`，同时发送使用说明和升级说明。有旧版时，先导出标注备份并保留原文件，关闭工作台与浮窗，按安装提示卸载旧版；卸载时不勾选清除应用数据，再完成安装。软件不会因安装包而附带发送者资料库。候选仍在实机验收阶段。

## 发送端：导出带文件的资料包

1. 打开拾签，确定要交接的文件；少量文件可多选，同类资料可点击左侧对应标签后选择全选结果。
2. 点击工具栏的「导出资料包」图标；也可以从偏好设置进入「导出资料包」，按对话框选择导出范围。
3. 选择包的保存路径，文件扩展名是 `.sqtagpack`。核对包含的文件数，等待任务完成，确认没有失败或缺失文件。
4. 将这个 `.sqtagpack` 文件通过 U 盘、共享文件夹或你们平时使用的传输方式发给同事。包内包含选定原文件副本、标签、备注、收藏信息，请先确认这些资料适合交接。

不要只发 `.sqtagbackup`：它用于恢复标注数据库，不包含原文件。也不要把普通文件夹导出当作资料包：普通文件复制不会自动带齐拾签标注。

## 接收端：导入到本机

1. 同事安装拾签后，将 `.sqtagpack` 下载到本机磁盘；首次提示 AI 时可以选择「暂不设置」，再读快速上手说明。
2. 打开「偏好设置」→「导入资料包」，选择收到的包和本机目标文件夹。
3. 核对导入预览与数量后开始导入，等后台任务完成；不要在复制期间拔掉移动介质。
4. 在工作台查看导入文件，核对标签、备注、收藏，尝试打开图片与文档。文件复制到接收端目录，不依赖发送者的原路径。新包按直接父文件夹名归类，如 `拾签资料-包ID/Pic/`、`Desktop/`；同目录重名文件加编号后缀。旧包优先用文件夹标签归类，信息缺失时放入「未分类」。
5. 若提示重复、损坏或某些文件失败，按结果处理，不反复强行导入。先保留原包，记录提示与诊断信息反馈。

AI 密钥属于各自电脑的配置，交接资料后如需 AI，由接收者自行设置。

## 第一次跨电脑验收建议

先交接一份小包：两张合成图片、一份文本，全部添加「交接测试」标签，给其中一份加备注和收藏。记录发送数量；在另一台电脑导入后比对数量、内容、标签、备注、收藏和能否打开。成功后再交接正式项目资料。

反馈时给出两端软件版本、Windows 版本、包大小、预期/实际文件数和是否出现提示。当前已完成的同机双库测试只能证明本机导出/导入链路，首次跨电脑验收仍需这个操作。
