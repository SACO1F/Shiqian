# 拾签 v0.3.0-alpha.3：玻璃浮窗与标签文件导出

更新日期：2026-10-09

## 标签浮窗

- 使用 Windows Acrylic 背景效果、透明 WebView、半透明面板和高光边框，适配浅色、深色主题。桌面透射效果取决于 Windows 的透明效果及系统合成支持。
- 移除「管理预设」页面；底部固定「添加标签」按钮，支持输入名称新建，也支持添加已有标签到浮窗。
- 每个标签右侧的九宫格按钮提供「修改名称」「导出标签文件」「从浮窗移除」「删除标签」。点击菜单不会触发拖拽标注。
- 修改标签名称会同步更新标签库及关联文件；重名失败保留输入。
- 「从浮窗移除」只隐藏常用标签，保留文件标注；「删除标签」会确认后删除标签和全部关联，原文件保留，可撤销。
- 常用标签最多显示 24 个；保留原有拖入文件标注、拖出标签标注、收起、展开、置顶和返回工作台功能。

## 同标签文件导出

入口：浮窗九宫格菜单 → 导出标签文件，或主窗口「管理标签」中标签右侧的下载图标。

1. 选择导出位置，或直接粘贴已有文件夹路径。
2. 点击「导出文件夹」。
3. 在导出位置内创建以标签名命名的新文件夹，将该标签的全部关联文件复制进去。不会受到当前主窗口搜索、分页或选择范围限制。
4. 完成后显示成功、失败数量，可以打开导出文件夹。

导出是普通文件夹，不是 ZIP 压缩包。复制实际文件，不是快捷方式；不移动或修改原文件，也不改变其标签。

### 命名与异常

- 目标已存在同名文件夹时自动加序号，不覆盖旧导出。
- 不同来源的同名文件自动加序号，保持可用扩展名；超长名称会缩短，Windows 不允许的字符和保留名称会处理。
- `_拾签导出清单.txt` 记录原始路径、实际导出名称、成功或失败原因。原文件本身与清单同名时也会自动避让。
- 已从资料库移除的记录不参与导出；缺失、无法访问、路径已被其他文件替换及复制时发生变化的文件记录为失败。
- 复制失败不会留下该文件的不完整副本；其他成功文件保留。若导出位置无法写入清单，会报错，不会把这次导出显示为成功。
- 不允许导出到应用自身资料库内部。
- 标签和关联路径在开始导出时读取快照；文件内容在复制时读取。复制期间请等待完成后再退出程序。

桌面验证使用独立资料库和合成文件。导出界面测试在路径输入框中填写独立测试目录，IPC、数据库查询与文件复制均为真实执行；未自动操作原生系统文件夹选择器。物理桌面拖拽、多屏和混合 DPI 沿用既有测试范围，不作为本次新增验证结论。
