# 拾签 v0.3.0-alpha.6：标题栏主题与浮窗控制

更新日期：2026-10-09

## 深色模式顶部修复

此前网页界面已切换为深色，但 Windows 原生标题栏没有同步，导致窗口最顶部仍然发白。现在主题切换同时更新工作台、浮窗与原生窗口主题，浅色、深色及跟随系统采用一致的有效主题。

## 浮窗大小与置顶

- 可拖动浮窗任意边缘或四角调整大小，右下角显示简洁的调整标记。
- 展开状态的尺寸范围为 280～900 像素宽、320～1000 像素高，标签列数随宽度自动变化，数量较多时滚动浏览。
- 顶部图钉按钮控制是否置顶。亮起表示置顶，再次点击可取消。
- 窗口尺寸和置顶选择保存在本地。原生调整事件经过合并后写入，避免拖动过程中逐帧保存。
- 收起保留当前宽度、变为 64 像素高的标题条；展开恢复原尺寸。收起期间暂时禁用调整大小，避免标题条意外拉伸。
- 右下角调整标记可获得键盘焦点，左右方向键调宽、上下方向键调高，每次 16 像素。

## 标签按钮与九宫格层级

标签按钮覆盖整块标签卡片，选中时整块显示更清晰的背景、边框及高光。九宫格编辑按钮独立覆盖在标签按钮上方，文字留出右侧编辑空间。

点击九宫格不会选择其他标签或启动标签拖动，仍可进行重命名、按标签导出、从浮窗移除和删除。标签按钮与九宫格保持两个独立的可访问按钮，避免嵌套按钮。

## 验证

使用独立 QA 资料库与合成文件，不操作个人资料库。

- 完整后端测试：64 项通过，1 项需要可观察 Windows Shell 场景的测试按既有规则跳过。
- 浮窗已有功能回归：10 组通过，包括真实标签写入、撤销、预设保存、收起展开及重新打开工作台。
- 新窗口控制与点击层级：6 组通过，检查实际原生主题、置顶状态、窗口尺寸、尺寸保存、收起与展开、重新创建窗口、最小尺寸布局和编辑命中。
- 九宫格编辑与按标签导出回归：5 组通过。
- TypeScript、Vite、Windows EXE 与 NSIS 安装包构建通过。

记录位于 `docs/evidence/floating-controls-core.log`、`floating-controls-regression.log`、`floating-controls-desktop.log`、`floating-controls-export.log` 和 `floating-controls-package.log`。

桌面检查通过 Tauri 原生窗口接口改变尺寸并确认状态；边缘调整使用系统原生拖拽接口，本次未新增完整物理鼠标拖动、多显示器混合 DPI 或全新 Windows 系统安装的验收结论。

## 使用新版

交付文件位于 `releases/v0.3.0-alpha.6/`。先关闭旧版标签浮窗，再退出旧版工作台，安装或运行新版。单独 EXE 需要电脑已有 WebView2 环境，安装包适合日常使用与分发。
