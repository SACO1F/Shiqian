# 拾签 v0.2.1：图片瀑布流与可收拢菜单

更新日期：2026-10-04。

## 图片优先的全部文件

原来的等高网格替换为瀑布流，图片按预览的实际比例显示；同一列里的下一张图片紧跟上一张，不再为统一卡片高度裁切普通图片。图片卡片默认隐藏文件名、格式、日期和大小，悬停或键盘聚焦时显示文件名和已有标签。完整属性仍在选中文件后的详情面板中查看。

PDF 首页也使用瀑布流。文本与其他没有图片预览的文件保留名称，损坏或不可用文件显示状态，便于辨认。极端长图的卡片高度设有上限，通过等比容纳显示，完整内容可用空格预览或默认程序查看。

工具栏继续提供「瀑布流视图／列表视图」切换。不同文件范围保留各自的视图偏好。瀑布流复用原来的文件选择、批量操作、空格预览和拖拽标注入口，并保留虚拟渲染与分页。

## 调节图片大小和列数

文件数量旁边增加图片大小控制：

- 点击 **＋** 放大图片并减少列数。
- 点击 **－** 缩小图片并增加列数。
- 拖动「瀑布流列数」滑杆直接调整；默认 3 列，允许 2～8 列。
- 窗口较窄或打开详情面板时，可用列数会自动减少；恢复宽度后沿用原先保存的列数偏好。

图片卡片密度设置继续控制留白；列数独立控制图片大小。没有选中文件时，瀑布流会让出空的详情面板区域，把空间用于图片。

## 收拢左侧菜单

顶部路径左边的按钮可以收拢／展开菜单。收拢后保留「全部文件、待整理、收藏、最近加入、需要关注」图标，以及标签浮窗和偏好设置入口；悬停显示入口名称。「展开标签索引」可以直接恢复完整左栏。

列数与菜单状态保存在本地资料库，重启后保留，并随标注备份一起恢复。保存请求依次提交，正常关闭工作台前等待偏好保存完成。

## 本次范围

应用版本更新为 v0.2.1。此次实现的是图片浏览与导航改进，不代表此前路线中的多屏／混合 DPI、完整跨窗口物理拖拽验收、浮窗位置记忆或托盘功能已经完成。Agent 与浏览器插件仍处于文档规划阶段。
