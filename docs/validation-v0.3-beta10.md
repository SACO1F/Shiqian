# 拾签 v0.3.0-beta.10／RC 验收记录

日期：2026-10-10。Windows 开发电脑，真实生产 Tauri/WebView2，全部写入测试限制在独立合成资料库。未访问真实用户资料。版本为本地稳定候选，不代表正式稳定发布或 GitHub 已发布。

## 本轮实现

1. Ctrl+A 使用与“全选结果”一致的分页检索、过期查询检查及 1,000 项上限；输入框保持文字全选。
2. 加载与前端启动错误页面增加 32px 标题栏、窗口控制和原生拖动入口，避免无装饰窗口在启动异常时失去可见控制。
3. 关闭过程增加共用的进行中标记，重复请求不重复保存／确认／检查；流程结束后释放标记，保留备注草稿、任务门禁和浮窗显示时隐藏工作台的规则。
4. 增加 Windows CI 工作流、可复用的版本化回归参数、多端口隔离 QA 启动和正常退出辅助脚本。CI 尚未上传执行，本地执行等价的依赖安装、生产前端、核心、版本门禁和原生构建检查。

## 验证边界与稳定版门槛

- bootstrap 等待／错误由测试拦截 IPC fetch 模拟，窗口 API 与后续成功启动是真实执行；这不覆盖原生建库失败对话框、磁盘满或整个 WebView 无法启动。
- 标题栏双击采用 DOM 事件验证到原生状态；未用物理鼠标验收标题栏拖动、边缘缩放和 Windows 吸附。八个边缘区域显示正确不等于缩放手势已通过。
- 浮窗几何为本机真实窗口及模拟失效坐标，不能替代双屏混合 DPI、跨窗口原生拖标签、断屏和休眠唤醒。
- 旧版兼容为独立 EXE 的数据读取／恢复，不是安装器覆盖升级；尚未覆盖所有偏好或 AI 密钥。
- 交接为同机独立资料库，不是另一台实体电脑；短时持续操作不是 8 小时全天使用验证。核心故障注入不替代系统级权限不足、磁盘满等实机测试。
- 干净 Windows、无 WebView2、实际覆盖安装、卸载重装、跨电脑交接、多屏物理操作和全天运行仍待验收，按 [RC 实机清单](beta10-rc-checklist.md) 记录。

本轮完成的是候选实现与本机回归。正式稳定版需补齐清单 P0，并关闭数据损失／损坏、启动／升级失败及核心流程阻断问题。
