## 安装与升级

| 场景 | 操作 | 预期 | 实际结果 |
| --- | --- | --- | --- |
| 干净系统 | 新用户安装并启动 | 工作台可打开、可加入文件 | |
| 无 WebView2 | 在测试环境缺少 Runtime 时安装 | 依赖安装有明确反馈，完成后能启动 | |
| 覆盖升级 | 旧版保存标签、备注、收藏、外观设置，退出后安装新版 | 数据完整、设置保留、显示 Beta.3 | |
| 备份恢复 | 导出备份，修改合成标注，再从备份恢复 | 标注恢复，原文件保留，显示保护备份日期 | |
| 卸载重装 | 仅在测试用户下卸载并重装 | 核对数据保留是否符合安装器提示 | |

## 操作和显示器

| 场景 | 操作 | 预期 | 实际结果 |
| --- | --- | --- | --- |
| 普通文件加入 | 加入合成文件及一个缺失路径，补齐缺失文件后重试 | 只重试失败路径，已有记录不重复 | |
| 跨设备资料包 | 另一台电脑校验并导入资料包 | 标签、备注、收藏可使用，接收路径属于本机 | |
| 大资料包后台 | 开始导入后收起，继续搜索和保存备注 | 进度可查看，准备期间工作台可操作 | |
| 取消和退出 | 取消进行中的任务，再退出 | 取消完成后可退出，没有新增残缺标注 | |
| 混合 DPI | 双屏 100% / 125% / 150% 组合移动浮窗、拖标签 | 目标准确，标签位置和窗口大小可用 | |
| 浮窗状态 | 改大小、切换置顶、收起、重启 | 状态与位置合理，不出屏 | |
| 深浅主题 | 切换主题，打开任务、诊断和浮窗 | 文字清晰，控件和模态框保持一致 | |
| 诊断反馈 | 预览并用原生选择器导出 Markdown | 报告可保存；仅含版本、计数和状态 | |

## 全天使用与恢复

持续至少一个工作日，包含导入、标注、搜索、预览、任务取消和正常重启，记录内存及缓存变化。另测睡眠唤醒、移动盘断开再接入；断电和磁盘满只在可恢复的测试环境执行。
