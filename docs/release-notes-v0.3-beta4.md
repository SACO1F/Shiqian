# 拾签 v0.3.0-beta.4

日期：2026-10-10。针对五项交互问题的修复候选，数据库保持 schema 2。

1. 瀑布流宽度重排时取消逐卡滚动补偿，避免反复展开详情产生累计滚动漂移。
2. 详情标签候选排除已应用标签，移除七项截断；使用原有滚动容器展示全部匹配标签。批量标注保留可以补齐的标签。
3. 标签浮窗隐藏创建，先恢复并校正屏幕位置，再显示；首次显示后再次设定客户区尺寸，避免 Windows 非装饰窗口首次显示的尺寸变化。
4. 文件状态、标签匹配方式、文件排序、文件卡片密度共用选择器视觉规则，支持浅色和深色。

安装、升级和资料交接见 [使用指南](beta-v0.3-beta4.md)。验证证据见 [验收记录](validation-v0.3-beta4.md)。
