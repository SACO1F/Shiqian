# 拾签 v0.3.0-alpha.2：界面与标签操作

更新日期：2026-10-09

## 本次变化

- 去除工作台标语、英文装饰、重复的本地存储说明和重复页面标题；浮窗标题与提示也作了精简。
- 保留必要的错误、导入状态、AI 内容发送说明、备份恢复提醒。
- 左侧标签右侧新增铅笔入口，可直接进入重命名；管理面板中点击标签名称也能编辑。
- 重命名继续使用同一标签 ID，所有关联文件、当前标签筛选、标签池与已打开的标签浮窗同步更新。文件本身和文件夹名称不会被改动。
- 重名冲突显示具体错误并保留草稿；空名称不能保存，Esc 或取消按钮放弃修改，Ctrl+Z 可撤销成功的重命名。
- 文件浏览区右下角新增「添加标签」悬浮按钮。打开详情栏后按钮会自动向左避让。

## 添加标签

未选中文件时，点击悬浮按钮并输入名称，将标签加入标签库。

选中一个或多个文件时，点击悬浮按钮，可以搜索并选择已有标签，也可以输入新名称后点击「添加」。同一次操作会应用到全部所选文件。

「管理标签」可从侧栏标签索引右侧或添加面板进入。原有桌面标签浮窗仍从左下角打开。

## 实现与兼容

本次沿用标签 ID 与文件关联关系，不新增数据库结构。标签重命名不会改变手工、文件夹或 AI 来源及 AI 确认状态。

自动文件夹标签仍按实际父文件夹名生成。如果把一个文件夹来源的标签重命名，后续导入或补齐仍可能按原文件夹名创建标签；重命名标签不等同于建立文件夹名称别名。
