# v0.3 支持环境与已知限制

2026-10-11。0.3.0-rc.4 为验收候选，未完成全部实机门槛，不是正式稳定发布。

- 交付目标 Windows 11 x64；需要 WebView2。Windows 10、ARM64、macOS、Linux 尚未列入本次验收支持范围。
- 安装按当前 Windows 用户进行。需要依赖时可能联网；干净系统/无 WebView2/实际覆盖安装仍待实机验证。
- 当前安装器和 EXE 未提供发布者代码签名；SHA256 可核对文件一致性，不能代替发布者签名。自动更新尚未实现。
- PDF 已内置第一页面预览，当前 PDF 上限 30 MiB。Word/Excel 内容阅读、PDF 翻页仍在后续计划中。
- 原文件保留原位置；移动/离线会影响打开，检查状态或重新关联，不因离线而删除标注。
- 标注备份不含原文件；跨电脑交接优先资料包。AI API Key 的跨电脑复制不在本版兼容承诺内，应在接收电脑重新设置。
- AI 为可选服务，启用后根据设置处理新导入资料。已有标签导入的手工标注规则保留；未确认 AI 标签仍需用户审核。使用引导本身不调用模型。
- 完成的引导状态保存在本机 WebView 存储，清理该存储可能再次显示；以资料库路径区分。
- 混合 DPI、多屏、跨窗口物理拖拽、断屏、休眠唤醒与八小时使用仍需实机验收。短时循环和同机双库不代替这些结果。

## 反馈与支持

复现时记录版本、Windows/WebView2、显示器缩放、操作步骤、预期与实际结果。偏好设置可预览并导出诊断；用户决定是否发送，不会自动上传。发送前检查并脱敏，不发送原文件、路径、API Key 或个人资料。代码和历史发布见项目 GitHub SACO1F/Shiqian。

遇到数据问题先保留升级前备份和程序生成的保护备份，见[升级与恢复说明](upgrade-v0.3.zh-CN.md)。
