## 后端测试覆盖

1. Unicode NFC、大小写折叠、首尾空白和标签长度校验。
2. 同路径重复加入幂等；不同路径同内容保留独立记录。
3. 移除再加入保留 ID、标签和备注；旧撤销记录识别版本冲突。
4. 批量标签操作只撤销实际变化；任一文件版本冲突时事务整体回滚。
5. 备注与文件属性分别校验版本；拒绝旧版本覆盖；备注长度按用户可见字符检查。
6. 文件名、标签、备注跨字段组合搜索；百分号、下划线和引号按普通文本处理。
7. 全部／任一／排除标签及待整理范围；目录筛选不会混入同名前缀目录。
8. 分页排序稳定，没有重复记录；会话撤销深度为 20。
9. 重命名与删除标签连续撤销；不把无关的后续变化误当作可撤销状态。
10. 缺失文件、重新关联、已占用路径拒绝及同位置文件身份变化。
11. 应用数据目录排除；图片缩放、缓存、版本变化和损坏图片降级。
12. UTF-8、UTF-16 文本预览；截断长中文文本时不拆开 UTF-8 字符。
13. 相同大小和时间、不同文件身份的预览缓存相互隔离。
14. 包含 WAL 最新提交的备份往返；恢复前保护备份；损坏内容和校验和拒绝。
15. 重新打开数据库后的持久性；拒绝未来 schema；恢复中断标记的启动校验。
16. 10,000 条文件记录的组合查询测量。

## 桌面验证覆盖

基础流程连接真实 Tauri WebView，经实际 IPC 调用 Rust 后端和 SQLite，没有模拟文件库。覆盖递归加入、单文件多标签、备注保存与切换、批量标签撤销、备注搜索、连续搜索、PDF 首页、纯文本转义、损坏图片、收藏、软移除、备份恢复、重新加载、网格／列表和主题切换。未发现未捕获的前端异常。

补充检查包括：

- Space 在文件区打开预览，并再次关闭。
- 合成中文输入法 composition 事件期间不启动半成品关键词查询。
- 备注版本冲突时显示错误并保留本地草稿；经确认可重新读取数据库内容。
- 在 960×640、1280×800、1920×1080 的 WebView 视口下，文件区和详情面板保持可用，没有根页面横向溢出。
- 284 个真实文件记录下，DOM 中只渲染视口附近的文件；滚动加载所有分页后，Ctrl+A 能选择 284 项。
- 对浏览器侧外部 HTTP(S) 请求设置阻断并记录，测试流程未发出外部网络请求。
- 编辑后尚未等待 500 ms 自动保存计时器，直接调用原生窗口关闭；关闭后的 SQLite 包含完整新备注。新进程启动后再次读取一致。

## 查询测量

本次机器为 Windows 11 x64，系统版本 `10.0.26200.0`，16 个逻辑处理器。构建工具为 Node.js 25.8.1、Rust 1.97.1；WebView2 为本机已安装版本 154.0.4258.37。

数据集：10,000 个文件记录、40 个标签、30,000 个文件标签关联，以及长度变化的中文备注。执行 120 次包含文本和标签条件的查询：

| 指标 | 实测 |
| --- | ---: |
| p50 | 93.95 ms |
| p95 | 102.36 ms |
| 最大单次查询 | 112.83 ms |
| 数据准备及全部查询 | 11.25 s |

这是 **Rust debug 测试构建中的数据库服务层测量**，不包含界面输入防抖、IPC、缩略图或绘制时间，不代表所有硬件上的端到端响应保证。数据通过数据库测试准备；此结果不能用来证明一万份原文件的磁盘导入速度。

## 已修复的验证发现

- 自动保存成功后，避免详情中的旧文件对象把新备注重新覆盖回旧显示值。
- 撤销只推进本次涉及实体的历史版本，不掩盖其他实体上的外部变化。
- 初始化时不重复提交相同空搜索，避免用户刚选中的文件被清空。
- 搜索尊重输入法组合输入；文件快捷键限制在文件区域，保留表单控件的正常键盘行为。
- 预览缓存包含文件身份，防止重新关联到相同大小和时间的其他文件后复用旧预览。
- 长 UTF-8 文本截断保留完整字符；Windows 上先关闭备份数据库连接，再回收临时目录。
- 测试资料库与 WebView 状态均位于独立目录，避免测试影响正常资料库。
