# 拾签 v0.2.2 验证记录

日期：2026-10-04。环境：Windows x64、最终 Tauri Release EXE 的真实 WebView 与 IPC。测试使用 `qa/data-v022-regression` 独立资料库及合成图片。

## 缺陷复现与修复

在 v0.2.1 可执行文件中，使用 7 张横图、竖图和方图复现了重叠。初始加载、连续切换回 3 列、调整为 1190px 窗口宽度、重载已保存的 4 列布局四个场景未通过边界检查。证据为 `evidence/gallery-layout-baseline.json`。

原实现于普通 effect 中清空虚拟列表测量值；这可能发生在尺寸观察器已经报告新尺寸之后，既有 DOM 没有下一次尺寸变化时便持续使用默认高度。修复在 layout effect 中重建布局并同步读取已挂载卡片高度；图片加载并更新实际宽高比时，也在绘制前同步高度，避免重新挂载时短暂重叠。测量仍由虚拟列表管理，离屏卡片不一次性渲染。

加减按钮现按列数命名、排序和执行：左侧「－」减少一列，右侧「＋」增加一列，保留滑杆与上下限禁用。文件结构和数据库结构无变化。

## 复现方法

1. 执行 `npm ci` 和 `npm run package`，用带 Pillow 的 Python 执行 `scripts/make-gallery-fixtures.py`。
2. 将最终 EXE 复制到 `qa/shiqian-v022-test.exe`；设置 `SHIQIAN_QA_DATA_DIR` 为工程 `qa/` 内独立库，运行 `node scripts/launch-qa.cjs qa/shiqian-v022-test.exe`。
3. 设置 `PLAYWRIGHT_MODULE` 为可加载的 Playwright 模块路径，先运行 `node scripts/gallery-layout-regression.cjs`，再运行 `node scripts/gallery-smoke.cjs`。
4. 用 v0.2.1 EXE 和另一独立库执行专项脚本，加 `--baseline` 可复现旧版。时序缺陷触发次数可能不同；记录的基线运行有四个失败场景。

脚本验证资料库位于 `qa/` 后才写入合成数据，不能针对正式资料库执行。
