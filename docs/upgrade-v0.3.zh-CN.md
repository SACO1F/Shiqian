# 拾签 v0.3 升级、备份与恢复说明

2026-10-11。当前交付为 0.3.0-rc.4 验收候选，正式 0.3.0 尚未发布。

## 从 alpha.10 / Beta 升级

1. 在旧版偏好设置导出 `.sqtagbackup` 标注备份，保存到数据目录外。备份不包含原文件，重要文件另行备份。
2. 在偏好设置打开数据目录，退出旧版后可复制整个目录留存。不要在程序写入时复制 SQLite 文件作为可靠备份。
3. 关闭浮窗和工作台，等导入/导出完成。启动浮窗后关闭工作台可能只是隐藏工作台；先关闭浮窗，再退出工作台。
4. 在原 Windows 用户下运行 `Shiqian-v0.3.0-rc.4-Windows-x64-setup.exe`，通常使用原安装位置。安装器如询问卸载/保留资料，不选择删除应用数据。
5. 使用新快捷方式打开，确认版本和数据目录；核对数量、标签、备注、收藏、设置及浮窗。无引导记录的旧版用户会看到一次 AI 提醒，已有配置可保留。
6. 先操作少量测试资料，再继续日常整理。不要同时使用两个版本写同一资料库。

应用标识保持 local.shiqian.desktop，安装按当前用户进行。独立 EXE 也使用该用户的应用数据目录，不是 EXE 旁边的便携资料库。若库为空，先核对 Windows 用户和偏好设置的数据目录，不立即重新导入或恢复。

EXE 数据兼容检查不等于安装器覆盖安装成功；实机安装升级、所有 AI 密钥和卸载行为见[实机验收](stable-release-acceptance.md)。

## 出现问题时

记录版本、操作步骤、错误和数据目录；先停止会修改资料的操作并保留备份。需要恢复时，使用偏好设置的备份恢复入口，审阅文件数和覆盖提示，保留程序生成的保护备份。标注恢复不能找回已删除的原文件。

不把直接运行旧 EXE 当默认回退方式。新版资料库是否可被旧程序读取需单独确认；未确认时保留完整升级前副本，在隔离位置或测试用户下使用匹配旧版读取，避免旧程序写入新库。

## 发给同事

- 只交付软件：发送 setup.exe 与本版使用说明。发安装包不会携带你的文件或标签。
- 交付原文件及标注：在工作台选择文件导出资料包 `.sqtagpack`；同事在偏好设置导入，选择接收文件夹，核对结果。
- 只交付标注备份：原文件仍需独立传送并确认路径关系；备份不等于跨电脑资料包。
- 校验下载：用 SHA256SUMS.txt 对照文件校验值；PowerShell 可执行 `Get-FileHash -Algorithm SHA256 -LiteralPath '安装包完整路径'`。
