## 实现边界

「全选结果」遵循当前标签、关键词和其他筛选条件，分页读取完整结果；查询条件改变或更新的查询开始后，旧请求不会提交选择。为兼容现有后端批量事务，每批最多 1,000 项，超过上限明确提示缩小范围。

保留既有文件夹标签的自动生成、详情展示、索引筛选；仅从详情添加标签候选中移除。侧栏没有替换图标节点，继续使用原有展开/收起缓动，并支持减少动态效果。

首次测试脚本将另一个目录的标签误认为当前文件已有标签，随后把断言改为校验文件版本和完整关联不变；另一次精确文本定位没有包含同一容器内的「取消选择」，实际页面已选中 120 项，改为检查选择状态后通过。保留初始日志 `docs/evidence/beta5-tag-sidebar-initial.log` 与 `docs/evidence/beta5-tag-sidebar-selection-initial.log`。

本轮未执行安装器覆盖安装或卸载器，也未重复完整跨设备交接、多屏混合 DPI、全天运行验收。

使用步骤见 [Beta.5 指南](beta-v0.3-beta5.md)。
