## 文件预览需求（已纳入，尚未开发）

详见[预览研究](file-preview-research-2026-10-10.md)及详细计划第 4.4 节。稳定版交付门槛通过后，按以下顺序推进：

1. 复用现有 PDF.js，补齐总页数、翻页、缩放和按需渲染。
2. DOCX 卡片优先内嵌缩略图，缺失时显示标题/首段；放大时按需加载只读阅读器。
3. XLSX/CSV 卡片显示首表前几行；放大时支持工作表切换和虚拟滚动，显示已保存的结果，不承诺自动计算公式。
4. 做有无依赖的双构建对比，首期 Word/Excel 安装器增量目标不超过 2 MiB；记录内存、冷/热预览耗时和缓存增长。
5. 旧版 Office 和高保真排版作为后续可选增强，不把完整办公转换引擎塞入基础安装包。

以上均为计划，当前 PDF 仍只预览第一页，Word/Excel 尚未内置内容阅读器。

本轮已清理生成缓存和合成 QA 资料，源码、证据与发布包保留，见 [清理记录](cleanup-2026-10-10-0.3.0-beta.9.md)。继续开发先运行 `npm ci`，再运行 `npm run desktop`。

## RC.2 稳定交付进度

已完成全量核心回归、首次启动/重启、界面回归、alpha.10/Beta.12 实际 EXE 数据升级与同机资料包测试，补齐交付文档和正式发布检查。已收到安装保留信息后可用的同事反馈，具体版本/环境待补齐。下一步优先用小资料包做跨电脑验收，再完成实机 P0 记录；通过后才重新构建 0.3.0 正式版本。文件预览仍按上述 v0.4 计划推进。

RC.2 修复交接目录按原父目录归类，并统一导出范围 Glide Select，改进详情聚焦和卡片缓进缓出过渡，固定选择计数指示器。新资料包 v2 需双方升级，旧 v1 继续可读。新增三项核心测试及原生界面专项；接收电脑应重新用新包复核目录布局。

RC.3 保留 RC.2 的图片/卡片缓动，同时抵消内部 UI 缩放，修复 Markdown 图标拉伸和标签变大/变小。新增浅深色、展开/收回及减少动态效果的原生尺寸采样回归。

RC.4 增加列数加减的卡片移动过渡；连续调整窗口时保留卡片已有列分配、实时更新高度，不重启缩放动画。新增连续视口尺寸与列数容量回归；RC.3 图标和标签尺寸回归继续通过。
