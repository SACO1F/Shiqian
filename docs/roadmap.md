## 3. alpha.17 体验迭代

[React Bits 动效评估](react-bits-motion-plan-2026-10-09.md) 已给出候选组件与适配方式。本轮五项已完成并通过专项验证，最终记录见版本说明。下一阶段建议进入 v0.3 Beta 的稳定性与资料交接：

1. 添加、编辑标签弹窗与菜单统一短位移淡入；重叠图层和焦点返回清晰。
2. 文件多选勾选框增加轻微填色和勾线反馈，不改变卡片大小或点击区域。
3. 新标签／接受 AI 标签后的出现过渡只播放一次，文件、侧栏和浮窗同步保持现有规则。
4. 浮窗最近三步记录新增滑入，旧记录平滑离开，保留无撤销设计。
5. AI 任务清楚展示处理中、待确认、完成、失败，支持取消与失败重试；进度来自实际任务状态。

完成后再评估文件数量动画及可见瀑布流卡片重排。强液态玻璃、3D、粒子和全局光标效果暂不列入工作台。

## 4. 同事使用与资料交接

beta.1 已实现 `.sqtagpack` 资料包：可按所选文件、全部文件或标签导出原文件、标签关系及来源、备注和收藏。接收端先校验预览，再复制到新的本地目录并追加到当前库，避免依赖发送端路径。同名标签复用，已有资料不覆盖；重复包导入受限，支持取消和中断记录。

发送端与接收端的独立合成资料库交接、旧版升级、1 GB 任务取消、中文长路径和文件散列已验证。见 [Beta 说明](beta-v0.3-beta1.md) 与 [验收记录](validation-v0.3-beta1.md)。本机两份库不等于另一台实体电脑验证。

Beta 后续优先级：

1. 干净 Windows 电脑安装／首次启动／缺少 WebView2 的依赖安装；覆盖安装与卸载后数据保留验证。
2. 同事电脑实际导入资料包；不同盘符、网络盘和实际权限限制；每位试用者回报是否能独立完成交接。
3. 双屏 100%／125%／150% 混合 DPI 原生拖拽，浮窗置顶／缩放／位置恢复。
4. 全天使用和更大的图库基线，记录预览缓存、内存变化、长任务取消与异常恢复；发现具体问题后修复。

Beta.2 的功能和本机专项验证已完成；干净电脑、多屏及全天验收继续保留，完成后再扩大分发或进入稳定版。根目录批量映射、已存在文件记录的内容去重／合并策略留到 v0.4；本版通过新的文件副本避开覆盖冲突。

## 5. AI 标注的后续工作

已有模型辅助分类，不应再将其列为“尚未接入 AI”。重点转向质量和规模：

- 固定 30～50 份经人工确认的图片／文档样本，记录已有标签复用率、新建议采纳率、错误建议及处理耗时。
- 批量审核支持接受、修改、忽略；继续保持未确认建议不进入可添加标签池。
- 同义词与重复标签建议合并，并保留手工标签、文件夹标签和已确认标签。
- 显示真实处理数量、失败原因与重试结果；对服务成本增加可配置处理范围和预算控制。

当前 AI 自动标注属于模型辅助分类。Agent 需要进一步实现查询工具、计划编排与可靠提交；旧 [Agent 分析](agent-integration.md) 的“没有模型接入”描述是 2026-10-02 的历史状态，未来接口设计仍可参考。

## 6. 浏览器与 Agent 的共同前置工作

- 抽取桌面和浮窗共用的业务服务，避免扩展或 Agent 直接修改数据库。
- 保留稳定文件／标签身份、版本检查和来源信息。
- 增加网页与摘录对象时先定义迁移、旧客户端兼容边界及新版备份。
- 外部请求具备版本握手、授权范围、请求 ID、幂等规则与可解释错误。

浏览器具体规格见 [browser-extension-design-v0.2.md](browser-extension-design-v0.2.md)；文件名中的 v0.2 是设计文档版本，不表示扩展已交付。

## 7. 开发与验收方式

每轮：明确使用场景与验收样例 → 实现 → 专项检查 → 更新文档 → 打包 → 小范围体验反馈。状态区分待开发、开发中、待验证、已完成；原生拖拽、显示器缩放和安装升级必须经过真实环境验证。

优先记录实际数据：标注是否准确、是否丢失资料、滚动与搜索耗时、错误可否恢复、AI 建议是否被采纳。工期需在具体范围和实机环境确认后估算，不以已有功能数量推算整体完成率。

v1.0 以数据恢复、安装升级、核心交互和目标环境验收完成为条件。
