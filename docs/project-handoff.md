# 项目打包与 GitHub 仓库说明

整理日期：2026-10-02。应用版本仍为 v0.2.0，本次调整为项目目录整理、README 展示和 Agent 方案分析；未新增 Agent 功能或重新编译应用。

## 本地开发位置

主开发副本位于 `D:\AI\Shiqian`，源码直接放在根目录。原工作区保留，可用于回查；后续建议在 D 盘副本继续开发，避免两个位置分别修改。

```powershell
Set-Location D:\AI\Shiqian
npm ci
npm run desktop
```

依赖、Rust 构建缓存和运行时用户资料库不属于源码包，需要重新安装依赖。软件仍使用既有用户应用数据目录；移动项目不等于迁移用户标注资料库。

## 本地目录与上传范围

| 目录或文件 | 本地保留 | GitHub 位置 |
| --- | --- | --- |
| 源码、依赖锁文件、脚本、文档、合成数据测试证据 | 项目根目录及各子目录 | 主仓库 |

`releases/`、`local-only/`、`packages/` 已加入 Git 忽略规则；依赖、临时测试库、环境凭据文件和构建目录同样排除。完整本地包保留 `local-only` 中的素材，适合作为自己的归档；线上仓库与预发布附件不含这些素材。

## 三种源码与交付快照

1. **当前仓库源码**：包含新版 README、路线和 Agent 分析，是继续开发的入口。
2. **v0.2.0 原发布源码 ZIP**：保持当时交付字节与 SHA256 不变，便于核对对应安装包；没有本次新增文档。
3. **本次完整本地包**：包含当前已提交源码、历史 v0.2.0 交付文件和本地保留素材；不包含 `.git` 历史、依赖、构建缓存和真实用户标注资料库。解压后可使用，Git 历史从远程仓库取得。

本次打包清单以 SHA256 记录文件内容；ZIP 校验文件位于包旁边。验证包括源文件迁移校验、原发布文件校验、Git 忽略范围、文档链接、ZIP 条目与内容校验，以及远程提交同步检查。
