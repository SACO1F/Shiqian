## 三种源码与交付快照

1. **当前仓库源码**：包含新版 README、路线和 Agent 分析，是继续开发的入口。
2. **v0.2.0 原发布源码 ZIP**：保持当时交付字节与 SHA256 不变，便于核对对应安装包；没有本次新增文档。
3. **本次完整本地包**：包含当前已提交源码、历史 v0.2.0 交付文件和本地保留素材；不包含 `.git` 历史、依赖、构建缓存和真实用户标注资料库。解压后可使用，Git 历史从远程仓库取得。

本次打包清单以 SHA256 记录文件内容；ZIP 校验文件位于包旁边。验证包括源文件迁移校验、原发布文件校验、Git 忽略范围、文档链接、ZIP 条目与内容校验，以及远程提交同步检查。

## v0.3.0-beta.1 更新

本地交付位于 `releases/v0.3.0-beta.1/`，包含安装包、EXE、源码快照、使用说明、验收记录与 SHA256SUMS。原验证构建的 EXE 与安装包字节保持不变；本轮更新 README、仓库说明、清理记录和源码快照后重新生成校验清单。

`scripts/package-release.py` 用于更新当前 Beta 的源码快照、指南和校验清单，已有应用资产保留；它不会重新构建程序。应用源码有修改时应先重新构建并更新版本化应用资产，再生成交付快照。

`scripts/clean-local.ps1 -DryRun` 可预览固定生成目录的清理范围。`releases/`、`packages/`、`local-only/`、正式资料库和 Git 历史不属于清理范围。
