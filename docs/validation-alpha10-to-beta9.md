# alpha.10 → Beta.9 数据兼容验证

日期：2026-10-10。使用两个已发布版本的实际 Windows 独立 EXE，依次打开同一独立合成资料库 `qa/alpha10-to-beta9/library`，没有访问真实用户资料。

## 静态检查

alpha.10 源码快照和 Beta.9 当前配置均为：应用标识 `local.shiqian.desktop`、产品名拾签、NSIS 当前用户安装、数据库 schema 2；默认资料库通过 app_data_dir 定位。无需逐个安装中间版本。

## 实际执行

1. alpha.10 加入合成文本，添加普通标签与文件夹自动标签，保存备注、收藏、深色主题、260px 侧栏宽度和浮窗预设；导出旧标注备份。
2. 退出独立 alpha.10 实例，再使用 Beta.9 打开同一测试资料库。
3. 验证文件 ID、名称、路径、身份、加入时间、备注、收藏及关联标签完全相同；主题、侧栏宽度和浮窗预设保留。
4. 在 Beta.9 检查 alpha.10 备份，并执行恢复；恢复前保护备份存在，恢复后备注保留。

结果：全部通过。

证据：[alpha.10 建库](evidence/alpha10-beta9-seed.log)、[Beta.9 打开与备份恢复](evidence/alpha10-beta9-upgrade.log)。脚本：`scripts/alpha10-beta9-upgrade-smoke.cjs`。

## 边界与建议

这是实际程序的数据兼容测试，不是在另一台实体电脑上执行安装器覆盖升级。未覆盖用户真实资料、加密 AI 密钥、所有历史偏好或不同机器环境。安装器是否自动处理原安装位置及快捷方式仍需同事实机核对。

可直接发送 Beta.9 安装包，推荐升级前导出 `.sqtagbackup`、另行备份原文件，关闭浮窗与工作台，再使用同一 Windows 用户安装新版。升级后核对版本与数据。旧版独立 EXE 与安装版通常读取同一用户资料库，出现空库时先检查用户与数据目录，不要盲目覆盖恢复。

使用步骤见 [Beta.9 使用说明书](user-manual-v0.3-beta9.zh-CN.md)。
