# 拾签资料包格式 v1

适用版本：v0.3.0-beta.1。文件扩展名 `.sqtagpack`；容器为 ZIP。实现为 `src-tauri/src/transfer.rs`，不复制 SQLite 数据库。

## 条目

```text
manifest.json
manifest.sha256
files/00000/原文件名.ext
files/00001/同名文件.ext
…
```

本版导出使用 Stored 压缩方法，避免已压缩图片重复压缩的 CPU 开销；导入接受底层 ZIP 支持的压缩类型，但限定解压大小。条目数量恰好为文件数 + 2，拒绝未知、重复、链接与目录条目。每条文件路径必须与清单下标和文件名完全相符，不使用归档路径直接拼接接收目录。

`manifest.sha256` 是清单原始 UTF-8 字节的 SHA-256 小写十六进制，恰好 64 字节。清单是 JSON 对象，字段按下表定义；未知顶层和文件条目字段拒绝。校验用于发现损坏，不提供发布者签名或加密。

| 清单字段 | 类型 | 约定 |
| --- | --- | --- |
| format | 整数 | 当前必须为 1 |
| packageId | 字符串 | 新导出创建 UUID；导入收据用于同库重复拦截 |
| appVersion | 字符串 | 导出程序版本 |
| createdAt | 毫秒时间戳 | 包生成时间 |
| files | 数组 | 1 至 10,000 项，顺序决定归档与接收编号 |

| 文件字段 | 类型 | 约定 |
| --- | --- | --- |
| name | 字符串 | 原始文件名；不接受路径分隔符、控制字符、Windows 保留名、结尾点／空格；UTF-8 最多 240 字节 |
| entry | 字符串 | 必须为 `files/下标五位数字/name` |
| bytes | 无符号整数 | 解压后准确字节数；全包最多 8 GiB |
| sha256 | 字符串 | 原文件字节散列 |
| note | 字符串 | 最多 10,000 个 Unicode 字素 |
| favorite | 布尔值 | 收藏状态 |
| added / modified | 毫秒时间戳 | 原记录加入时间、原文件修改时间；本版接受 1970 至 9999 年 |
| tags | 标签数组 | 最多 1,000 项；同文件禁止名称归一后重复 |

标签携带现有 `Tag` 序列化字段；关键字段为 `name`、`createdBy`、关系 `source` 与可选 `ai`。来源值为 manual／folder／ai；AI 关系必须具有 model、reason、updatedAt、confirmed。旧标签 ID、计数与版本只作为发送快照，导入不会拿旧 ID 替换当前库 ID。

## 读写与事务

- 导出先从库生成记录快照并返回预览指纹；正式导出再次比较。逐项打开原文件，核对记录身份与修改版本，流式复制并计算散列，结束后再核对版本。
- ZIP 完成并同步后才以不覆盖方式发布。发生异常或取消，临时包清理；已有同名输出保留。
- 导入预览对每项完整读取核对长度与散列。正式导入再次校验包、比较清单指纹，避免预览后换包。
- 先在目标目录下创建 UUID 资料目录；恢复标记通过临时文件同步后发布，再逐项提取。提取到独立编号子目录，保持原文件名与时间。
- 完整提取后开启 SQLite savepoint。新建文件记录、复用名称匹配的标签、写入关系及来源、确认状态、备注和收藏，保存资料包导入收据及浮窗确认标签，再做完整性检查并提交。
- 不复制界面或 AI 服务设置，不创建 AI 任务，不按内容散列合并当前文件记录。保留原库，新增副本；导入成功清空会话撤销。
- 正常失败／取消回滚记录，只删除该调用创建的文件和空目录，不递归删除用户目标目录。
- 异常退出后 WAL 决定数据库提交结果。重启检查收据，保留已复制文件与恢复说明；不自动删除未知目录。

## API 入口

| action | 作用 |
| --- | --- |
| package.plan | 通过文件 ID 列表、标签 ID 或全库生成导出预览 |
| package.export | 指定保存路径和预览指纹，执行导出 |
| package.inspect | 校验资料包并生成导入预览 |
| package.import | 指定资料包、接收目录和预览指纹，追加导入 |
| package.status | 读取运行状态、阶段与累计处理字节，不等待数据库锁 |
| package.cancel | 请求当前资料包任务取消；每个读取块与提交前检查 |

同一应用实例只执行一个校验／导出／导入任务。确认导入若普通文件加入任务未完成则拒绝；导入持有 Store 锁，其他库操作顺序等待。取消不等待 Store 锁，因此大文件处理时仍可响应。

未来修改格式需增加版本，保留清楚的兼容边界。目录映射、既有文件内容去重、标签合并、网络磁盘专用容错与签名分发不包含在格式 v1。
