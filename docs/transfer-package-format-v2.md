# 拾签资料包格式 v2：原目录分类

适用版本：v0.3.0-rc.2。沿用 `.sqtagpack`、ZIP 条目命名与 v1 的完整性/限额检查。

清单 `format` 为 2，每个文件新增必填 `parentFolder`，仅保存直接父文件夹名称，不保存发送端绝对路径或完整目录树。归档内仍用 `files/00000/原文件名.ext` 保证条目唯一；编号仅在包内，接收目录改为 `拾签资料-包ID/Pic/原文件名.ext` 等原目录分类。

父文件夹名必须是单个可在 Windows 使用的名称，拒绝路径分隔符、控制字符、保留名、尾点/空格与超长名称；验证通过后才创建目录。导入重复文件名（按 Windows 大小写不敏感规则）自动添加 ` (2)`、` (3)` 后缀，保留不同文件内容，不覆盖已有文件。

不同来源路径具有同名父文件夹时归入同一分类目录；不重建发送者的盘符或完整层级。来源标签、备注和收藏继续保留；为防止将用户名等完整路径传出，包内只记录分类名。

新版读取 v1 和 v2。v1 没有 parentFolder，优先使用合法的 source=folder 标签名；没有该信息时归入「未分类」。旧包无法恢复已经丢失的原目录信息。

旧版本只支持 v1，不能导入 v2。交接双方应升级至 RC.2 或后续支持 v2 的版本。程序不能把旧版数字目录自动移走；如需重新交接，发送端生成新的包，接收端核对后处理旧记录和旧文件。

安全、事务、收据和异常恢复仍沿用 v1；同库重复包保持拒绝。取消/失败只清理本次创建的文件和目录，原文件与既有资料保留。
