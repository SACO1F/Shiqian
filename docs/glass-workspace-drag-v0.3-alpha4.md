# 拾签 v0.3.0-alpha.4：工作台玻璃风格与拖拽反馈

更新日期：2026-10-09

## 拖拽标签至工作台

- 浮窗标签进入文件区域后，鼠标旁显示标签名称。对应文件出现清晰边框、柔和呼吸光圈和「松手添加」提示，图片轻微放大。
- 同一文件上的持续移动不会反复重启动效；切换文件会移动到新的目标。
- 放到空白或工具栏区域会提示放到具体文件；不会错误标注其他文件。
- 松手后显示处理中状态，成功出现确认光圈及「已添加」提示；已有标签会提示「已有此标签」，失败显示红色反馈。
- 拖拽结束事件不会提前清除处理中和完成反馈；离开工作台、取消或 Esc 会清除悬停。
- 支持瀑布流与列表两种视图。
- 边框与提示作为独立覆盖层显示，图片缩放只发生在预览内，不修改卡片和虚拟列表的测量尺寸。
- 系统开启减少动态效果时，保留边框与文字反馈，关闭呼吸、缩放和确认动画。

## 一致的玻璃设计

工作台与标签浮窗共用浅色、深色玻璃色板。工作台增加柔和渐变背景、半透明侧栏、顶部栏、详情面板、状态栏、搜索与筛选控件，以及统一的圆角和高光边框。添加标签悬浮按钮也采用玻璃表面。

玻璃样式不改变瀑布流的列数、图片比例和布局逻辑；图片仍然保持清晰，卡片信息继续按已有的悬停和详情规则显示。

- TypeScript 检查、Vite 生产构建和 Windows EXE / NSIS 安装包构建通过。
- 真实 Tauri 工作台的 5 组交互检查通过：目标定位与动画稳定性、目标切换与取消、真实标注及失败反馈、文件离开当前筛选后的确认位置、浅色／深色／窄窗口与减少动态效果。
- 瀑布流的 35 个回归场景通过，覆盖不同列数、窗口尺寸、详情栏、侧栏收拢、极端长宽比和滚动中的布局变化。

验证记录位于 `docs/evidence/glass-workspace-desktop.log`、`docs/evidence/glass-workspace-gallery.log` 和 `docs/evidence/glass-workspace-package.log`。

## 使用新版

先关闭旧版标签浮窗，再退出旧版工作台。安装或运行 `v0.3.0-alpha.4`，打开标签浮窗，将标签拖到工作台文件上即可看到反馈。单独运行 EXE 需要电脑已具备 WebView2 运行环境；安装包适合日常使用与分发给同事。安装包已成功生成，本次未在全新 Windows 环境上执行安装验收。
