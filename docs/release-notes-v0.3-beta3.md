# v0.3.0-beta.3 更新说明

日期：2026-10-10。定位：稳定候选，正式稳定版需完成实机验收。

## 改进

- 浮窗保存物理屏幕位置和逻辑尺寸；重启恢复位置。打开和展开时按显示器可用工作区校正位置及尺寸，原显示器不在时回到主屏范围。
- 浮窗折叠不覆盖展开尺寸；位置记录不进入跨设备标注备份。
- 原生关闭和退出入口增加后台任务保护；普通文件加入取消后，界面等待任务停止再退出。
- 退出被任务阻止时显示任务反馈，不把任务等待误报为备注保存失败。
- 备份状态重新读取时清除上次错误，避免恢复正常后仍显示旧错误。
- 打包前核对六处版本和安装包／EXE 原生产品版本。已有交付程序与当前构建不同则停止，避免复用旧构建；显式刷新后重算校验值。

## 延续

资料包后台执行、失败重试、备份状态、恢复提示与诊断导出延续 Beta.2。数据库格式保持 schema 2。

## 交付与边界

本轮在隔离资料库使用合成内容验证。干净 Windows 安装、缺少 WebView2、安装器覆盖升级、卸载重装、混合 DPI、多屏物理拖拽、跨设备与全天使用仍需实际设备验收。

此候选不宣称上述实机项目已通过，不自动发布 GitHub。详细实测结果见 [验收记录](validation-v0.3-beta3.md)。
