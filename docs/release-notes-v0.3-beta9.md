# 拾签 v0.3.0-beta.9 · 工作台体验与稳定性更新

本次预发布汇总 Beta.1 之后的 Beta.2–Beta.9 更新，提供 Windows x64 安装包、独立 EXE、源码快照、使用指南、验收记录与 SHA-256 清单。仍属于候选版本。

## 工作台与浮窗

- 撤销、刷新、菜单切换进入最上方自定义标题栏左侧；移除原生可见标题及下方多余工具栏。右侧提供最小化、最大化／还原和关闭，空白区域及窗口边缘接入原生拖动／缩放。
- 排序与收藏、导出资料包、移除同时常驻；图标按钮提供动态悬浮提示，全选／取消使用胶囊外形与弹性反馈。
- 修复重复点击不能取消选择、详情反复开关导致瀑布流滚动上移、标签候选重复和展示不全、右侧标签拖动提示受限。
- 工作台创建或使用普通标签后同步到浮窗，保留原有预设且不重复；文件夹和待确认 AI 标签继续隔离。
- 统一四处下拉菜单、玻璃按钮边缘及侧栏图标对齐，保留浅深色与减少动态效果支持。
- 同标签文件可全选并共同追加标签，批量处理每次最多 1,000 个文件；浮窗位置与展开尺寸保存、恢复和显示器边界校正。

## 稳定性与交接

- 增加后台任务查看、重试和取消；后台任务未收尾时检查退出流程。
- 资料包处理继续加强校验、取消回滚、追加导入与备份保护；诊断报告只包含版本、计数与状态，不含用户文件名、路径、正文、标签或服务配置。
- 自定义关闭按钮继续走备注与设置保存、任务检查；浮窗仍打开时隐藏主工作台，可从浮窗重新打开。

## 验证与边界

最近一次后端核心回归为 Beta.6：94 项通过、0 失败、2 项可选压力测试忽略。Beta.9 真实生产桌面回归通过窗口控制、常驻工具栏、选择和提示、标签候选及四处选择器；详情连续切换 12 轮，滚动位置保持 1800。

物理鼠标跨窗口拖拽、标题栏拖动和边缘缩放、混合 DPI、不同实体设备、覆盖安装／卸载与全天运行仍需补齐。请先退出旧版，升级前导出标注备份；完整边界见 [Beta.9 验收记录](validation-v0.3-beta9.md)，使用见 [Beta.9 指南](beta-v0.3-beta9.md)。
