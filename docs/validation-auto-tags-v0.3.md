真实桌面流程还验证了：重复导入不会重复请求；重新识别保留手工/文件夹/已确认标签；推理期间用户修改会拒绝旧结果；取消后不写入在途结果；设置界面不回显已存密钥；备份往返保留确认状态并关闭 AI。

浏览器中的标签数据和 IPC 为合成夹具。桌面测试则运行真实发布程序并导入真实合成文件，模型服务器只返回预先定义的测试标签。两类测试的范围不同，均不等同于真实模型质量评测。

## 仍需区分的范围

1. 未配置实际云端或本机推理模型，未验证某个供应商的准确率、延迟、费用或所有模型兼容性。图片识别要求用户选择视觉模型。
2. 1 项跳过的测试为原生资源管理器命中探针，需要指定屏幕位置与可见测试文件。跨窗口物理拖放、多屏和混合 DPI 沿用此前的验收限制。
3. NSIS 安装器构建完成，程序在本机运行验证；未在一台全新 Windows 电脑上安装验收。程序仍依赖 WebView2 Runtime。
4. 扫描 PDF 暂无 OCR；Office 使用文字摘录，不完整解析图表、公式或页面布局。超过限制会报告未支持或文件过大。
5. 安装前可以在 v0.2.2 中导出备份。首次升级自动保存 schema 1 恢复副本；旧程序不能直接读取 schema 2。
6. 开发模式的虚拟瀑布流重测会输出已有的 React `flushSync` 生命周期警告；这不属于未捕获异常。生产程序的布局场景全部通过，本次未改动该虚拟布局实现。

原先的沙箱构建与浏览器访问阻塞已解除，本次不再以独立核心入口代替完整桌面验证。测试没有读取个人资料库或向外发送用户文件。
