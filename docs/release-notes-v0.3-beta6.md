# 拾签 v0.3.0-beta.6

日期：2026-10-10，数据库 schema 2。

1. 标签拖动提示不再被固定右侧预留宽度限制；按实际尺寸避让窗口边缘。
2. 四处选择器改为 Glide Select 风格的统一组件：平滑弹出/收回、滑动高亮、选中勾选、键盘操作与视口避让。保留绿色主题，减少动态效果时关闭动画。
3. 工作台显式创建和使用普通标签后，同步到已打开的浮窗；已有快捷标签保持，不重复添加；文件夹和未确认 AI 标签继续排除。
4. 两个添加标签按钮移除白色描边及内侧亮线，保留玻璃底色和外阴影。

使用见 [Beta.6 指南](beta-v0.3-beta6.md)，验证见 [验收记录](validation-v0.3-beta6.md)。视觉参考：[React Bits Glide Select](https://reactbits.dev/c/micro/glide-select)。
